# Trusted Guardian — Day 0

**Date:** 7 October 2026

## What I Did

Today I created the GitHub repository for my **Trusted Guardian** project and set up the initial project structure.

I also added the MIT License and created a `blogs/` directory to maintain a record of the project's development.

## What I Learned

Today I understood how GitHub repositories, branches, commits, and open-source licenses fit into a software project.

I also learned that making a project public does not mean publishing every internal detail. Sensitive implementation details, private data, model information, and security-critical information should be protected.

## Key Takeaway

**Build openly, but protect what could compromise the security of the system.**
